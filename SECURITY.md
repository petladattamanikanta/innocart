# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability within InnoCart V2, please send an email to the security team or open a confidential security advisory.

Please include:
- Description of the issue and potential impact
- Steps to reproduce or proof-of-concept
- Affected service endpoints (e.g. WebSockets, Razorpay webhooks, JWT authentication)

We will respond promptly to acknowledge receipt and work on a fix.
